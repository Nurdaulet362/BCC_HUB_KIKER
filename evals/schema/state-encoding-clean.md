# Представление статуса заказа

REQ-1. После подтверждённой оплаты заказ имеет состояние «Оплачен».
REQ-2. GET /order возвращает status как строку: "paid" для оплаченного заказа, "awaiting" для ожидающего оплаты.
REQ-3. Успешный ответ GET /order имеет HTTP 200.

## Приёмка

| Исходные условия | Действие | Ожидаемый результат |
| --- | --- | --- |
| Оплата заказа подтверждена | GET /order | HTTP 200, status="paid" |
