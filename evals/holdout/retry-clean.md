# Повторная доставка

REQ-1. Первый запрос с данным operationId создаёт одну заявку и возвращает её номер.
REQ-2. Повтор того же запроса с тем же operationId возвращает номер уже созданной заявки и не создаёт новую.
REQ-3. Запрос с другим operationId создаёт отдельную заявку с новым номером.

## Приёмка

| Исходные условия | Действие | Ожидаемый результат |
| --- | --- | --- |
| Для operationId=A создана заявка 701 | Повторить тот же запрос с operationId=A | Номер 701, число заявок не изменилось |
| Для operationId=A создана заявка 701 | Отправить запрос с operationId=B | Новая заявка с другим номером |
