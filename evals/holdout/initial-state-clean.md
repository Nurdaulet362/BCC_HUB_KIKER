# Настройка уведомлений

REQ-1. До первого сохранения уведомление выключено, а порог равен 25 000 тенге.
REQ-2. GET /settings возвращает текущую настройку: enabled — целое число, 0 означает выключено, 1 означает включено; amount — целое число тенге.
REQ-3. При успешном чтении сервис возвращает HTTP 200.

## Приёмка

| Исходные условия | Действие | Ожидаемый результат |
| --- | --- | --- |
| Настройка ещё не сохранялась | GET /settings | HTTP 200, enabled=0, amount=25000 |
