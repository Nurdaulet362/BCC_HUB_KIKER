# Выгрузка списка операций

## Требования

- **REQ-1.** Экран выгрузки принимает дату начала и дату окончания по календарю Asia/Almaty.
- **REQ-2.** Если дата окончания раньше даты начала, экран показывает сообщение «Проверьте даты» рядом с датой окончания. Файл в этом случае не формируется.
- **REQ-3.** При корректных датах клиент скачивает CSV с колонками date и amount. Включаются только операции между указанными датами включительно, по дате операции в Asia/Almaty.

## Приёмка

| Исходные условия | Действие | Результат |
| --- | --- | --- |
| Есть операции 1, 2 и 3 ноября | Запросить период 1–2 ноября | CSV содержит операции 1 и 2 ноября |
