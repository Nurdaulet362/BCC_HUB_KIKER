# Выдача квитанции

## Правила

- **REQ-1.** После оплаты заказа экран показывает кнопку «Скачать квитанцию».
- **REQ-2.** По кнопке для оплаченного заказа скачивается PDF с номером заказа и суммой платежа в тенге.
- **REQ-3.** Пока заказ не оплачен, квитанция недоступна, а экран показывает статус «Ожидает оплаты».

## Приёмка

| Исходные условия | Действие | Результат |
| --- | --- | --- |
| Заказ 401 оплачен на 5800 ₸ | Скачать квитанцию | PDF содержит номер 401 и сумму 5800 ₸ |
| Заказ 402 не оплачен | Открыть заказ | Экран показывает «Ожидает оплаты», квитанция недоступна |
