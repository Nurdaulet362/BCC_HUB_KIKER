# Сдача решения

[← К README](../README.md)

Поля ниже соответствуют тексту формы BCC-HUB × Maqsut Narikbayev University, предоставленному владельцем проекта. Саму форму заполняет и отправляет участник.

## Ссылка на репозиторий

```text
https://github.com/Nurdaulet362/BCC_HUB_KIKER
```

Указывайте основную ветку проекта. В её корне находятся код агента в `kiker/`, `requirements.txt`, `.env.example` и `README.md` с установкой и одной командой запуска. Выданное ТЗ находится в `examples/requirements.md`.

Репозиторий оставлен приватным по решению владельца. Требование формы допускает предоставленный доступ: до отправки нужно дать жюри возможность открыть репозиторий. Одна ссылка не даёт доступа к приватному коду. Получение доступа жюри пока не подтверждено.

## Команда запуска агента

После установки зависимостей, активации окружения и заполнения `.env`, из корня проекта:

```sh
python -m kiker examples/requirements.md report.md --json result.json
```

Эта строка подходит для поля «Команда для запуска агента из терминала». Она выполняет новый анализ выданного ТЗ, показывает прогресс и создаёт `report.md` и `result.json`. В README описаны все предварительные шаги. Для Windows приведён вариант с прямым путём к Python из виртуального окружения.

## Файл отчёта

Прикрепите [`examples/report.md`](../examples/report.md) — настоящий, автоматически сформированный отчёт KIKER через Gemini по выданному документу. Размер — 25 952 байта, меньше лимита формы 10 МБ. Содержимое не редактировалось вручную.

В паспорте сохранена версия анализа `e1baa9da76c3ba4be4460c7033440425a8a880c6`; последующие изменения интерфейса и README не меняют этот паспорт. [Происхождение входа и отчёта](../examples/README.md).

## Видео — необязательное поле

В репозитории есть [демо на 96 секунд](https://github.com/Nurdaulet362/BCC_HUB_KIKER/blob/submission/demo.mp4). Оно показывает интерфейс и сохранённые реальные результаты, без ожидания нового анализа.

Форма описывает другой формат: **3–5 минут**, запуск агента, процесс анализа и получение готового отчёта; ссылка — **Loom, YouTube или Google Drive** с доступом по ссылке. Текущая запись на GitHub этому формату полностью не соответствует. Поэтому это необязательное поле можно оставить пустым. Если прикладывать видео, нужно подготовить запись по указанному сценарию и разместить её на одном из перечисленных сервисов; такой внешней ссылки пока нет.
