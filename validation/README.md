# Как читать доказательства

- `release-121` — итоговый код e1baa9d: реальные прогоны, повторные проверки, браузер, PDF и происхождение отчётов.
- `development-117` — первые изменения проверки доказательств и выбор LOW; промежуточные результаты.
- `development-118` — ложный конфликт бизнес-состояния и типа данных, прерванная диагностическая серия и ошибка HTTP 503.
- `development-119` — основной набор 7/8 и baseline 3/8; ложный вопрос о выдуманном API.
- `development-120` — два неуспешных повтора с вопросом о пустых датах.
- `extended-2e0dae6` — опубликованная ранее диагностика 5/8 против 3/8.
- `history-d23a93d` — предыдущий опубликованный комплект проверок.

Время и версия внутри каждого отчёта имеют приоритет над названием папки. Неуспешные и прерванные попытки не считаются успешными. Файлы `trace-*.json` содержат ответы модели на учебные документы; ключей API в них нет.
