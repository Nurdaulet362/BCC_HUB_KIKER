# Пример для воспроизведения

- `requirements.md` — исходный документ организаторов, скопированный без изменений.
- `report.md` — Markdown-отчёт, автоматически сформированный KIKER через Gemini 26 ноября 2026 года. Текст не редактировался вручную.
- `result.json` — тот же прогон для импорта в локальный интерфейс через «Открыть отчёт».

Команда для нового анализа из корня проекта после настройки окружения и `.env`:

```sh
python -m kiker examples/requirements.md report.md --json result.json
```

Результаты нового запуска сохраняются в корень проекта и не перезаписывают примеры в этой папке. Вывод модели может отличаться от сохранённого прогона.
