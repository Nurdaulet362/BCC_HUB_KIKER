# Проверка качества KIKER

26 ноября 2026 · код `e1baa9da76c3ba4be4460c7033440425a8a880c6` · Gemini 3.1 Flash-Lite · LOW · temperature 0 · интервал 8 секунд · таймаут запроса 90 секунд. Во всех проверочных сериях модель вызывается заново; повторное открытие готового отчёта не входит в показатели качества.

## Критерий успеха и границы измерения

Успех короткого случая означает: найдены все размеченные конфликты с нужными источниками, нет лишних замечаний и отклонённых записей. Ошибка API — неуспешная попытка. Дополнительно проверяются количество замечаний, цитаты, исходный SHA-256 и версия. Это проверка соответствия небольшой известной разметке, не оценка общей точности на банковских ТЗ.

Основной набор содержит 8 случаев. Дополнительные 8 документов закреплены до изменения анализа в коммите `0e04feb`, но после обнаруженного ложного конфликта типов использовались для доработки: здесь они называются **расширенной регрессией**. Пара из двух случаев кодирования/типов также создана для настройки. Примеры и ожидаемые ответы подготовлены с помощью ИИ в процессе разработки. Независимой разметки аналитика и человеческого пилота нет.

Baseline выполнен на `2873193` с тем же Gemini, LOW, temperature 0, исходниками, системным промптом и схемой. Совпадение системного промпта подтверждено SHA-256. Его настройка интервала — 15 секунд, но все 8 baseline-случаев завершились одним HTTP-запросом, поэтому внутридокументная пауза к ним не применялась. KIKER делает дополнительные модельные проходы и программные проверки, поэтому качество и стоимость нужно рассматривать вместе.

## Работа продукта и время

Пройдены **44 модульных теста**, **9 браузерных проверок** на широком экране и при ширине 390 пикселей, проверки CLI и обработка текстового PDF. Проверены сохранение решения после перезагрузки, фильтр незавершённых решений, неизменность скачанного отчёта и сравнение версий. Настоящий вызов Gemini выполнен через загрузку файла в интерфейсе; повторный запуск с включённым повторным использованием вернул тот же результат без запроса модели.

Время анализа включает модельные запросы, паузы и сетевые повторы, но не измеряет труд аналитика. При временных сбоях 503/таймаутах длительность заметно меняется. Подробные события попыток находятся в `results.json`. Экономия времени человека пока не измерена.

## Какие неуспешные результаты сохранены

- Предыдущая опубликованная диагностика `2e0dae6`: KIKER 5/8, один запрос 3/8; лишние вопросы о чистых CSV/квитанции и пропуск повторной заявки.
- Итерация `12ad9e2`: четыре успешных контрольных результата и один сетевой сбой на квитанции. Далее `2dfea58` прошёл основной набор 8/8 один раз; это промежуточный результат, не финальная версия.
- Итерация `7586453`: дополнительный пример начального состояния получил ложный конфликт integer/boolean. Завершены четыре случая; следующий прерван после выбора доработки. Первый запуск полного ТЗ через UI закончился HTTP 503, успешного отчёта не создано.
- Итерация `2873193`: основной набор 7/8, появился лишний вопрос о формате даты для выдуманного API. Полный UI-отчёт содержал 5 замечаний и 1 отклонённую запись. Начало следующей серии прервано после выбора доработки.
- Итерация `ed0af63`: два CSV-повтора вновь получили вопрос о пустых датах. После этого добавлена проверка явно разрешённых пустых/необязательных входов с положительными контролями, где такой вход действительно разрешён.

Неуспешные прогоны не входят в число успешных финальных проверок и доступны в папках истории. Правила выбора периода, исключённой операции, области API и пустого ввода — часть программного конвейера; результат нельзя приписывать только пониманию модели.

## Что остаётся неизвестным

Переносимость на новые банковские ТЗ, доля полезных замечаний по мнению независимых аналитиков и экономия их времени не измерены. Формальная проверка цитаты не доказывает правильность рассуждения. Ограниченные проверки области сценария могут требовать расширения на новых формулировках. Сравнение «не повторилось» не доказывает исправление.

Пилот **не проведён**: участников пока нет. Подготовлены [протокол](PILOT.md) и пустая [форма наблюдений](pilot-observations.csv). Репозиторий остаётся приватным; доступ жюри и получение материалов организаторами не подтверждены.
